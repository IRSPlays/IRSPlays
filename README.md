### 🧠 **About Me**

> *"Failing with Honour."*

I am **Haziq/IRSPlays**, an **AI, IoT, and Full-Stack Engineer** based in Singapore. I specialize in bridging the gap between high-level AI reasoning and low-level hardware execution. My mission is to build accessible technology that empowers people — from assistive wearables that beat $4,000 devices at $150, to neural architectures built from scratch on consumer hardware, to competition platforms serving hundreds of teams.

**Currently Working On:**
* 🦾 **Project Cortex V2** — 5-layer AI wearable with Gemini integration
* 🧠 **SNAP-C1 V5** — From-scratch neural architecture with resonance blocks
* 📊 **NRPC Platform** — Competition management for 500+ robotics teams
* 🎨 **Portfolio OS** — Interactive web portfolio as a functional operating system

#### 💡 **Project Highlights**

**Project Cortex V2** disrupts the $4,000+ assistive device market with:
* **5-Layer AI Brain:** Guardian (YOLO safety), Learner (adaptive detection), Thinker (Gemini reasoning), Guide (spatial audio), Memory (object recall)
* **~800ms latency** from question to audio response
* **Offline safety** via local YOLO detection (<100ms)

**SNAP-C1** represents honest research iteration:
* **V1-V4 documented failures** — every version taught what doesn't work
* **V5 "Resonance"** — binary embeddings, spectral mixing, elastic context (8K tokens)
* **100% trainable** on AMD DirectML (no frozen parameters)
